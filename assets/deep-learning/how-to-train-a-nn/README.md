# How to Train a NN slide assets

This directory contains PNG exports of the 2025 canonical slide deck for the
`How to train a NN` lecture note.

- Slides: `slides/slide-01.png` through `slides/slide-80.png`
- Source PDF: `2_backprop_2025.pdf` from the lecture row's `Ref` link
- Intended Notion usage:

```text
https://raw.githubusercontent.com/Basten1209/study-ai/<commit-or-branch>/assets/deep-learning/how-to-train-a-nn/slides/slide-04.png
```

For Notion image blocks to render these URLs without authentication, the GitHub
asset URL must be publicly accessible. If the repository remains private, raw
GitHub image URLs return 404 to Notion.
