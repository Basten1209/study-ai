# Architectures: Grid slide assets

This directory contains PNG exports of the 2025 canonical slide deck for the
`Architectures: Grid` lecture note.

- Slides: `slides/slide-01.png` through `slides/slide-81.png`
- Source PDF: `4_grid_archs_2025.pdf` from the lecture row's `Ref` link
- Intended Notion usage:

```text
https://raw.githubusercontent.com/Basten1209/study-ai/<commit-or-branch>/assets/deep-learning/architectures-grid/slides/slide-01.png
```

For Notion image blocks to render these URLs without authentication, the GitHub
asset URL must be publicly accessible.
